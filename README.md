Project Title: Low-Resource Neural Machine Translation (NMT)

Objective: Fine-tuning pre-trained sequence-to-sequence transformer architectures (mT5) on underrepresented regional languages like Sanskrit

Key Components:

Custom parallel dataset cleaning, tokenization, and subword fertility analysis.

PyTorch and Hugging Face Seq2SeqTrainer implementation pipeline configured with mixed-precision training (fp16).

Evaluation scripts utilizing multilingual sentence embeddings and cross-entropy loss tracking.

Tech Stack: Python, PyTorch, Hugging Face Transformers, Datasets, Google Colab.

This is going to be a project where I start from scratch and go to the entire model obviously with the help of mT5.
